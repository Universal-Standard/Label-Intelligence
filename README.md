# Label Intelligence

Label Intelligence is a production-grade, GitHub-native system for managing label definitions, enforcement logic, and contributor guidance.

## Goals
- Keep label behavior consistent across issues, pull requests, workflows, and automation.
- Provide a single source of truth for maintainers, contributors, and bots.
- Publish label guidance through GitHub Pages while keeping docs editable in-repo.

## Repository Features
- **Detailed label guides:** `docs/labels/*.md`
- **Central label catalog:** `docs/labels/index.md`
- **Governance docs:** `CONTRIBUTING.md`, `SECURITY.md`
- **GitHub-native automation:** scheduled sync and docs quality workflows
- **Community operations support:** issue templates, PR template, and standard ownership policy

## Documentation Entry Points
- Catalog: [`docs/labels/index.md`](docs/labels/index.md)
- Operating docs: [`docs/index.md`](docs/index.md)
- Changelog: [`docs/meta/changelog.md`](docs/meta/changelog.md)

## GitHub Platform Onboarding
This repository is intentionally structured for:
- **GitHub Pages** (publish from `/docs`)
- **Discussions** (Q&A and label policy decisions)
- **Wiki** (long-form playbooks and governance history)
- **Issues** (documentation gaps, label requests, automation defects)
- **Projects** (roadmap and rollout tracking)

See [`docs/index.md`](docs/index.md) for setup and governance details.
