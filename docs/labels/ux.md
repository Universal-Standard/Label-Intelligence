# Label: `ux`

## Purpose
For user experience quality improvements spanning flows and interactions.

## When to Use
- Navigation, discoverability, and workflow clarity improvements
- Accessibility and interaction quality improvements

## When Not to Use
- Pure backend changes without user-facing impact

## Related Labels
- `frontend`
- `enhancement`
- `documentation`

## Sample Scenario
A pull request is opened to address work matching **ux** scope. During triage, maintainers confirm the intent aligns with this label and apply related labels for routing, risk, and size.
