# Security Policy

## Reporting a Vulnerability
Do not open public issues for sensitive vulnerabilities.

Report security concerns through private maintainer channels and include:
- Impacted area
- Reproduction steps
- Potential severity
- Suggested mitigation (if known)

## Security Handling in This Repository
- Security-related label guidance lives in `docs/labels/security.md`.
- Workflow and automation hardening changes should be reviewed with the `security` label.
- Dependency-related updates should include `dependencies` and relevant severity labels when applicable.
